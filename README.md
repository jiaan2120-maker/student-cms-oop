# 学生教务系统（面向对象版）

一个基于 Python 面向对象编程实现的控制台学生信息管理系统，用于练习"类与对象""对象列表管理""文件持久化"等知识点。

## 功能

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 添加学生信息 | 录入姓名、性别、年龄、联系方式、详细信息 |
| 2 | 删除学生信息 | 按姓名删除指定学生 |
| 3 | 更改学生信息 | 按姓名定位并修改全部字段 |
| 4 | 查找单个学生信息 | 按姓名查询并打印 |
| 5 | 查找所有学生信息 | 打印学生列表全部内容 |
| 6 | 保存学生信息 | 将内存中的学生列表写入 `students_data.txt` |
| 7 | 退出系统 | 确认后自动保存并退出 |

## 项目结构

```
学生教务系统（面向对象版）
├── main.py            # 程序入口
├── student.py         # Student 实体类
├── studentcms.py      # StudentCMS 业务类（增删改查/持久化/主循环）
└── students_data.txt  # 学生数据文件（启动时加载，退出时保存）
```

## 运行方式

需要 Python 3。

```bash
python main.py
```

启动后按菜单提示输入数字编号选择操作。

## 设计说明

- `Student` 只负责保存一个学生的属性，并通过 `__str__` 提供可读输出。
- `StudentCMS` 负责业务逻辑：内部用 `stu_list` 维护学生对象列表，启动时调用 `load_student_infor()` 从文件恢复数据，退出时调用 `save_student_infor()` 落盘。
- 数据以 `Student` 对象的 `__dict__` 列表形式序列化保存，加载时通过 `Student(**stu)` 重建对象。
